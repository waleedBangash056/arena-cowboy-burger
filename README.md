## 🍔 Project Overview

**Arena Cowboy Burger** is a modern, interactive web experience designed to showcase an artisanal burger brand through immersive visual storytelling and interactive 3D WebGL elements. 

Built with **React**, **Three.js** via **React Three Fiber (@react-three/fiber)**, and bundled with **Vite**, the site delivers rapid load times, fluid animations, and a responsive layout tailored for both desktop and mobile food lovers.

### ✨ Key Features

- **Interactive 3D Burger Scene**: Integrated WebGL scene rendering interactive models with smooth Orbit/Drei controls for an engaging user experience.
- **Craft Culinary Showcase**: Dedicated visual sections highlighting the cooking process—from flame-grilling and searing to artisanal cheeses and fresh ingredients.
- **Brand Story & Menu Highlights**: Structured, conversion-focused layout showcasing signature cowboy burgers and combos.
- **Performance Optimized**: Built using Vite for instant HMR, tree-shaking, and lightweight asset loading.
- **Responsive & Cross-Device Ready**: Full support across mobile, tablet, and desktop screens with custom web icons and PWA-ready assets.

### 🛠️ Tech Stack

- **Framework**: React
- **3D Graphics & WebGL**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Build Tool**: Vite
- **Styling**: Modular CSS / Utility CSS
- **Deployment**: Static Web Hosting (Vercel, Netlify, or GitHub Pages)
